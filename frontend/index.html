VideoEditorY

Edit a video by editing its transcript.

1. Load video + subtitles

The .vtt is optional — only needed for the "Generate edit with Claude" flow below. Skip it if you'll paste an AI reply manually instead.

2. Generate a readable outline (optional)

In Claude Desktop (or a claude terminal), attach/cd into this project folder. Click "Copy message for Claude" below, paste it as your first message, and send it — the message points Claude at AI_EDITING_INSTRUCTIONS.md so it reads the rules before doing anything. It'll read workspace/subtitles.vtt and write workspace/outline.md: the transcript broken into topic-based paragraphs instead of raw cues.

Or skip Claude entirely for simple cuts: check the box on any paragraph or sub-paragraph below to mark it for removal, then click "Cut selected sections" — no AI involved, the app uses the outline's own timestamps.

3. Describe the edit

Type the edit you want below. Either click "Generate edit with Claude" to send it through this app automatically, or click "Copy message for Claude" and paste it into Claude Desktop/terminal yourself — that message also points Claude at AI_EDITING_INSTRUCTIONS.md so it knows the rules and writes workspace/cuts.md for you.

If you gave Claude an editing instruction in Claude Desktop/terminal (Step 2 in AI_EDITING_INSTRUCTIONS.md), it should have written workspace/cuts.md directly — click above to load it, no copy-paste needed.

Or paste a reply from another AI manually

Paste the full structured reply you got back from ChatGPT (or another AI) after giving it AI_EDITING_INSTRUCTIONS.md plus your instruction and transcript — including its ## REMOVED section.

4. Review & render

Start End Dur. Text / reason

Plain render — keeps the original audio untouched, no voice-over, no music.

Or render with a custom audio mix (voice-over / background music)

Uses whatever voice-over audio you generated in "5. Voice-over text chunks" below, placed at the correct spot in the edited video automatically.

Download edited video

5. Voice-over text chunks

Text from everything your currently enabled cuts above would keep. If you ran Step 1 with Claude, this is one chunk per outline paragraph/sub-paragraph — whatever granularity the outline itself chose — with no overlaps, so nothing is covered twice or skipped. Without an outline, falls back to ~500-character chunks cut at cue boundaries. Use this if you're replacing the audio with text-to-speech: either click "Generate with Piper" on a chunk for a free, local, offline voice-over (no API key, runs on this machine), or copy the text into any other TTS tool and upload the result. Each chunk shows how many seconds of video it has to fill, and the check tells you if the audio is too long for that slot. The text in each chunk is editable — fix misheard auto-caption words, stray music tags, or wrong symbols before copying or generating, since that text is exactly what gets read aloud.
